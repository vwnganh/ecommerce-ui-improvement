- **Website tham khảo:** (https://www.cocoonvietnam.com/)
- **Khu vực cải tiến:** Giao diện danh sách sản phẩm.
- **Nội dung thực hiện:** Trình bày thông tin sản phẩm, hình ảnh, giá bán, phân loại sản phẩm và các nút thao tác.

## 3. Kỹ thuật HTML5/CSS3 đã thực hành

- **HTML5:** Sử dụng các phần tử semantic như `header`, `main`, `section`, `article` để tổ chức cấu trúc giao diện.
- **CSS Selector:** Sử dụng các bộ chọn để định dạng từng thành phần trong trang web.
- **Box Model:** Áp dụng `margin`, `padding`, `border` và `box-sizing` để kiểm soát kích thước, khoảng cách.
- **Flexbox:** Sắp xếp và căn chỉnh các thành phần bên trong thẻ sản phẩm.
- **CSS Grid:** Xây dựng bố cục danh sách sản phẩm theo nhiều cột.
- **Responsive Design:** Sử dụng Media Queries để điều chỉnh giao diện theo kích thước màn hình.
- **Hiệu ứng CSS:** Sử dụng `hover`, `focus-visible` và `transition` để cải thiện trải nghiệm giao diện.

## 4. Hướng dẫn chạy website

1. Tải repository về máy tính hoặc mở thư mục dự án.
2. Đảm bảo giữ nguyên cấu trúc thư mục và vị trí các tệp.
3. Mở file `index.html` bằng trình duyệt web để xem giao diện.

## 5. Những thay đổi đã thực hiện

So với phiên bản bài tập Buổi 1, các nội dung được cập nhật gồm:

- Cập nhật cấu trúc HTML cho giao diện danh sách sản phẩm.
- Bổ sung và điều chỉnh CSS để hoàn thiện bố cục.
- Sử dụng CSS Grid để sắp xếp các thẻ sản phẩm thành nhiều cột.
- Sử dụng Flexbox để căn chỉnh các thành phần bên trong thẻ sản phẩm.
- Điều chỉnh giao diện responsive cho các kích thước màn hình.
- Bổ sung hiệu ứng hover và focus cho các thành phần tương tác.
- Bổ sung thư mục hình ảnh sản phẩm và điều chỉnh đường dẫn hình ảnh.
- Điều chỉnh bố cục các nút thao tác trên màn hình nhỏ.
