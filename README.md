# Cocoon - Ecommerce UI Improvement

## 1. Giới thiệu
Bài tập xây dựng và cải thiện giao diện danh sách sản phẩm cho thương hiệu Cocoon bằng HTML5 và CSS3.

## 2. Công nghệ sử dụng
- HTML5: Xây dựng cấu trúc và nội dung trang web.
- CSS3: Thiết kế giao diện, bố cục và hiệu ứng.
- CSS Grid và Flexbox: Sắp xếp danh sách và các thành phần sản phẩm.
- Media Queries: Điều chỉnh giao diện phù hợp với nhiều kích thước màn hình.

## 3. Cấu trúc thư mục
```text
ecommerce-ui-improvement/
├── index.html
├── css/
│   └── style.css
├── images/
├── README.md
└── AI_USAGE.md
```

## 4. Chức năng giao diện
- Hiển thị danh sách sản phẩm.
- Hiển thị hình ảnh, tên, giá và thông tin sản phẩm.
- Các nút yêu thích, thêm vào giỏ hàng và mua ngay.
- Bố cục responsive trên các kích thước màn hình.
- Hiệu ứng hover và focus cho các thành phần tương tác.

## 5. Cách chạy
Mở file `index.html` bằng trình duyệt để xem giao diện.
